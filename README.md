# 💅 Agenda de Turnos - Uñas

Sistema de agenda de turnos para negocio de uñas.

## Características

- 📅 Agendar turnos (Lunes a Sábado)
- 💰 Precios en múltiplos de $500 ARS
- 💵 Registro de señas pagadas
- 📋 Listado de turnos con filtros
- 🔍 Búsqueda por cliente
- ❌ Cancelación de turnos

## Cómo usar

1. Abre la app en tu navegador
2. Agrega turnos desde la pestaña "Agendar"
3. Visualiza todos los turnos en "Turnos"
4. Busca o cancela desde "Buscar"

## Instalación en iPhone

1. Abre el link en Safari
2. Toca el botón Compartir
3. Selecciona "Agregar a pantalla de inicio"
4. ¡Listo! Funciona como una app nativa

## Tecnologías

- HTML5
- CSS3
- JavaScript (LocalStorage)
- PWA (Progressive Web App)
